# 下载与启动

首发准备中，当前没有公开下载地址。

主程序为 Windows x64 便携 ZIP。全部解压后双击 EmojiBridge.exe，保留同目录运行环境；不要仅拿走一个 EXE，也不要在压缩包预览中启动。日常入口不需要命令行。

| 文件类别 | 用途 |
| --- | --- |
| core 主程序 | 互通、素材库、编辑器及识字／跟随运行环境 |
| templates 模板扩展 | 主程序可选扩展；下载同版ZIP，原样放在EB文件夹内或旁边，生成时校验准备 |
| full-ready 完整包 | 主程序与模板扩展合包，与core二选一 |
| models 模型包 | 自动抠主体时按所选模型准备；也可使用程序内在线准备或离线模型导入 |
| 同款表情包 | 宣传片素材，解压后多选导入，不是模板扩展 |

视频处理的FFmpeg按需准备。初次加载模型、模板引擎或多帧作品可能需要等待。

正式发布时会在这里接入每个下载文件与SHA256校验文件，大小以最终附件为准。
