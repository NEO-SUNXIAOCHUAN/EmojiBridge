互通前，记住这两件事

1. 转入微信，会使用文件传输助手。

EmojiBridge 通过你本人的文件传输助手发送素材并添加表情，因此会占用文件传输助手的聊天上下文，产生相应消息记录。开始前请先处理好正在编辑的内容。

2. 自动操作客户端进行互通时，请不要移动鼠标。

请暂时不要点击、切换窗口或操作目标客户端，等待任务完成后再操作。如果需要中断，使用软件的暂停或停止入口。

开始使用

  • 使用 Windows x64。QQ 来源可直接读取本人的缓存目录，QQ 可关闭，点击“更新”刷新；自动操作客户端进行互通时再登录相应客户端。
  • 让目标客户端保持可操作，不锁屏、不切换账号、不遮挡正在操作的窗口。
  • 下载便携 ZIP 后完整解压，再双击 EmojiBridge.exe。保留同目录运行文件。
  • 遇到提示时按提示处理；反馈问题可提供软件版本、客户端版本和复现步骤，不需要上传账号数据库或聊天内容。
