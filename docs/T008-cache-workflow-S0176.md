# S0176 缓存直接使用与素材管理（2026-11-16）

从 S0175 / ca05c2b 接续，分支 codex/cache-workflow-S0176。以优化文件第二版 v1.7 及用户“读取不等于入库”的纠正为准，替代旧文档的强制入库和口袋复制后自动隐藏要求。

## 已实施流程

1. QQ 整个个人缓存目录递归读取实际完整可解码文件，包含旧缓存；不依赖 QQ 运行、面板翻页或可见页。稳定来源 ID、文件签名和摘要索引支持增删改；坏文件隔离、取消保留进度，目录暂不可读不当作全库删除，跳过目录链接。
2. 交互以本地 S0180 用户最后口述为准：互通与主素材库始终显示勾选框，没有单/多选模式。点击切换勾选，点后恰好一项即复制该项，多项或零项不复制；取消到剩一张复制剩下那张。清空/全选/翻页/刷新不自动复制。批量操作接收明确所选 ID。详见 `T008-selection-count-S0180.md`。来源文件及必要临时副本直接进入现有目标流程，不自动创建素材记录；仅明确“加入素材库”保存选中原件、精确去重。原整理保留，回收站重复可恢复；微信复用现有读取和原件适配。
3. 后台 QQ 每 15 秒本地扫描，微信数据库/WAL 变化触发既有读取；切页、隐藏口袋、托盘期间继续，取消后延迟恢复。口袋复制后保持打开，快捷键只切换显示，保留固定、贴边与位置；拖动/双击不误触单击复制。
4. QQ、微信、素材库分来源展示并标重复；同来源同条目刷新不增殖，疑似匹配不当精确重复。素材库精确原件仍复用一份，保留来源关系。
5. 文件夹支持单层/递归、结果定位及目录层级合集。schema 3 升级前备份数据库，旧合集和成员保留；改名、移动防循环和同级重名；删除合集不删素材，子合集保留。相似静图人工对比/明确操作，GIF 不按首帧自动合并。
6. 完整备份受管原件、合集、标签、常用、回收站、草稿、持久视频源、引用和相关设置，不把 QQ 全缓存当素材。持久保存/备份共用跨进程锁。恢复新目录，先验证成员大小/SHA/路径/SQLite，再重写引用；历史不自动执行，失败不覆盖原库。Windows 暂时占用仅有界重试原子发布。
7. 后台仅查官方 Release 元数据，点击更新才下载，保持轻量/模板/完整形态并核对 ZIP SHA 和成员。正常保存退出后独立助手切换；新界面/数据库/后台服务确认完成，失败回退代码并保留数据，无保存令牌不切换。助手带独立标准库，仅创建助手时短暂允许脱离 Job，随即恢复子进程退出约束。
8. 设置“下载并安装”复用固定 SHA/ABI 组件安装器，也可导入 ZIP，兼容已安装组件不重复下载。四组件沿用 S0174；轻量含 U²-Net、FFmpeg、OCR/视觉与 DLL 下载标记处理，模板版加模板，完整再含动漫/精细模型和 tiny。base/small/SAM2 仍选装。
9. 固定提交 OhMyMeme 缓存、复制、更新和相似图参考已审阅，pHash 派生部分有 GPL 来源/改动记录。agent-wechat 仅评估，未接入、登录或运行协议客户端；详见 S0176-agent-wechat-evaluation.md。

UIA/MSAA 优先，当前步骤缺能力才视觉，不写客户端内存。目标索引不可用不再无条件阻止首次新任务；未知发送仍先核验，不能自动重发。历史完成后的新明确任务按当前目标索引判断，不把旧记录当永久成员证明。
