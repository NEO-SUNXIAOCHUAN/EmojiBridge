EmojiBridge S0146 · Windows x64 本地候选

完整解压整个 ZIP，在 EB 文件夹双击 EmojiBridge.exe。无需管理员权限。
请不要只复制 EXE，不要在压缩包内运行。备用入口：启动EmojiBridge.cmd。
两个入口使用同一份程序、同一默认用户数据，不会清空旧库。
默认数据：当前用户 LocalAppData/EmojiBridgePilot/material-library。
需要完全隔离的试用库，可用“启动独立初始库（不动旧库）.cmd”。

首次启动后台准备随包素材，可继续浏览；“宣传片同款”合集逐项出现。
166 份主素材按完整 SHA256 去重，保留原件、透明和动画；已有内容不会重复建条目。
之后启动不重复导入，被删除的预置素材不自动复活。
设置 → 本地保存 → 恢复内置示例：明确恢复已删除的预置素材。
设置 → 本地保存 → 导入宣传片可编辑示例：15 份原生草稿在“创作”，2 个声明式模板在编辑器“模板包 / 体积”。
用户生成的作品、个人标签、收藏和已有草稿不会覆盖。

宣传片同款表情/素材：普通 PNG、GIF、WebP 等原文件，可直接复制另存。
其中“10_模板与效果浏览示例”是 309 份既有预览，不是新增模板，也不会自动导入收藏。
宣传片同款表情/可编辑工程：工程和模板原包，连同同目录媒体一起保留。
来源、许可边界见该文件夹“来源与使用记录.txt”和程序 THIRD_PARTY_NOTICES.md。
音乐、人物原声和宣传视频不属于随包表情。

包内带 Python、桌面运行时、基础抠图推理运行时及完整锁定模板组件/资源。
Windows 需已启用 .NET Framework 4.x，桌面宿主需要 Microsoft Edge WebView2 Runtime。
缺失时会提示；WebView2 官方安装入口：https://developer.microsoft.com/microsoft-edge/webview2/
FFmpeg 与大型可选模型沿用现有按需准备，可在设置或功能页下载/指定本地位置；网络失败可重试，已有组件直接复用。
不会把所有高级模型伪称为随包即用。未覆盖的外机、中文实体输入法与客户端兼容场景仍待测试。
